Formula syntax

Variables z and c, units i j k, constants pi e. Operators + − * / ^; the multiplication sign can be omitted: 2z, c z (1 − z), 0.3j.

Quaternions do not commute, so the order of factors matters: c z ≠ z c, a/b = a·b⁻¹.

Powers: integer ones exactly (z^5, z^-2), fractional ones via polar form (z^2.5), hypercomplex ones via exp(log(a)·b) (z^z).

Functions: exp log sqrt sin cos tan sinh cosh tanh atan (extended from the complex plane), abs (absolute value of each component), conj, norm = |q|, re.

Folds and Mandelbulb: boxfold(z, r) reflects components beyond ±r, spherefold(z, rmin, rmax) is a sphere inversion, bulb(z, n) is the Mandelbulb "triplex" power over the axes 1, i, j (angle from the j axis), bulbw(z, n) is Daniel White's original 2007 variant (latitude angle, negated j; trig-free for n = 2). Mandelbox: 2·spherefold(boxfold(z, 1), 0.5, 1) + c.

Hybrid: several formulas, each repeated for the given number of iterations, then the next one, in a loop.

Parameters: any other name is a real parameter with its own slider, e.g. scale spherefold(boxfold(z, fold), rmin, rmax) + c. Sliders update the image without recompiling. A parameter also works as a fold argument or a power (z^p).

Deep zoom: arithmetic and integer powers are computed in double precision, functions such as exp sin … stay in float. 2D perturbation works for formulas made of + − × ÷, integer powers and abs conj norm re.

Hypercomplex Fractals

by Artem Selivanov (broly)
github.com/broly

Real-time explorer of 4D hypercomplex fractals (quaternion and bicomplex) and Mandelbox / Mandelbulb hybrids, sliced to 3D and ray-marched in WebGL 2. Any formula you type is compiled to a shader with automatic differentiation for the distance estimate; deep zoom uses double-float arithmetic in 3D and perturbation theory in the 2D slice.
